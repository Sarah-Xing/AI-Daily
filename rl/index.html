  1. 机构：南洋理工大学、Skywork AI
    核心价值问题：可验证奖励 RL 里很多验证器只能证伪、不能证实——“通过验证”的样本里混着大量走捷径的假正例，直接强化它们等于奖励作弊，怎么在这种单边可验证设定下训练？
    方法：提出 NOPO，把“验证通过”当作未标注样本、只用可信的“验证失败”负样本做抑制更新：参考相对的负抑制损失 + 按未证伪比例缩放更新幅度的组级适配器。
    为什么值得看：不依赖完美验证器就能稳定提升，在代码、逻辑、数学基准上 pass@k 超过 GRPO 等基线，且推理时扩展与跨基准迁移都保持增益；对依赖单元测试、约束检查这类不完全验证器的 RLVR 训练有直接参考价值。

    Negative-Only Policy Optimization for One-Sided Verifiable Rewards

    关键词：强化学习（reinforcement learning）、可验证奖励（verifiable rewards）、RLVR、策略优化（policy optimization）

  2. 机构：威斯康星大学麦迪逊分校、KRAFTON
    核心价值问题：GRPO 等方法每步都要算旧策略与当前策略的似然比做重要性采样，成本不小——重要性比到底是不是稳定训练必需的？
    方法：提出 LGPO，用基于似然的门控实现软信任域约束，不再计算旧策略似然；证明去掉重要性采样修正不损害稳定性，真正起作用的是信任域机制。
    为什么值得看：与标准实现相比训练提速约 18%、峰值性能相当；更关键的是在全在线（on-policy）设定下 GRPO 会失效（比值恒为 1、约束永不触发），LGPO 仍保持稳定，给 LLM 的 RL 后训练提供了一个更便宜、适用面更广的优化器。

    Is the Importance Ratio Necessary for Stable Reinforcement Learning in LLMs?

    关键词：强化学习（reinforcement learning）、GRPO、信任域（trust regions）、LLM 训练（LLM training）

  3. 机构：复旦大学、美团、清华大学、北京大学、中国科学技术大学
    核心价值问题：RLVR 里靠熵鼓励探索，但普通熵分不清“有效推理的多样性”和“胡编乱造的多样性”，高熵常常只是退化——怎么度量真正有用的探索？
    方法：提出有效熵（Effective Entropy），只在有效推理子空间内度量多样性、过滤掉错误轨迹的噪声，并据此做出 VEPO 方法，把有效熵直接纳入 RLVR 训练。
    为什么值得看：在 1.5B 与 7B 的 DeepSeek-R1-Distill-Qwen 上，六个数学推理基准相对 GRPO 一致提升、重复采样成功率也有竞争力；“多样性幻觉”这个诊断本身就值得做 RLVR 的人注意。

    The Illusion of Diversity: Aligning LLM Exploration via Effective Entropy

    关键词：强化学习（reinforcement learning）、探索（exploration）、熵（entropy）、数学推理（mathematical reasoning）

  4. 机构：兰州大学
    核心价值问题：想让视觉语言模型拒绝有害图文请求，安全程度却只能靠调奖励权重间接控制——能不能把安全直接写成预算（有害求助率、过度拒绝率上限），让训练按预算精确达标？
    方法：指出约束 GRPO 的两处失效（评分器均值偏差决定拉格朗日乘子、组内标准化抵消惩罚），提出双通道约束 GRPO 修复控制通道。
    为什么值得看：在 Qwen3-VL-2B 上，held-out 有害求助率从 8.9% 降到 4.8%（未校准的预算控制只到 7.6%），过度拒绝率不超过 2%、MMBench 不变，HADES 未见基准上从 28.9% 降到 12.8%；对需要可控安全性的 VLM 后训练是实用的 recipe。

    Safety as a Budget: Calibrating the Control Channel of Constrained GRPO for Vision-Language Models

    关键词：约束强化学习（constrained RL）、视觉语言模型（VLMs）、安全对齐（safety alignment）、GRPO

  5. 机构：中国科学院大学、中国科学院软件研究所、联想研究院、北卡罗来纳大学教堂山分校、天津大学、北京交通大学
    核心价值问题：多轮 agent 的 RL 训练常把一条轨迹展开成多行训练样本，同一轮次结果会被重复计数、不同轨迹的目标质量也不均衡——这种“账算错了”的问题怎么修？
    方法：提出 Outcome-Mass Alignment（OMA），分两步：结果对齐（只按唯一源轨迹算结果统计）、质量对齐（在轨迹内聚合后控制总目标质量），不改动底层优化器的信用分配、重要性比与裁剪。
    为什么值得看：在 ALFWorld 的 GRPO 对照实验（两个模型规模）中均提升性能；问题本身很隐蔽——很多多轮 agent 训练管线都可能在不知不觉中重复计数，值得检查自己的实现。

    Outcome-Mass Alignment: Controlling Length-Dependent Trajectory Influence in Multi-Turn LLM Agent Reinforcement Learning

    关键词：多轮 agent（multi-turn agents）、强化学习（reinforcement learning）、信用分配（credit assignment）、轨迹优化（trajectory optimization）

  6. 机构：中国科学技术大学
    核心价值问题：推理分割里轨迹级奖励说不清“哪些 token 提供了有效视觉证据”，信用分配太粗——怎么把 token 级的信用分到真正起作用的推理步骤上？
    方法：提出 HISD，用目标消歧证据做 token 级信用分配：离线生成 Segment Hint，提示条件 EMA 教师给学生轨迹打分，只调整正优势的幅度、负优势不动。
    为什么值得看：在 ReasonSeg 测试集上比 DPAD 复现基线 gIoU/cIoU 各提升 3.00/3.55 个百分点，同时有效推理跨度平均缩短 80%–92%；把“提示”变成信用分配信号的思路也可迁移到其他需要细粒度信用的 RL 任务。

    Hint-Informed Self-Distillation for Reasoning Segmentation

    关键词：推理分割（reasoning segmentation）、强化学习（reinforcement learning）、信用分配（credit assignment）、视觉语言模型（VLMs）

  7. 机构：中国科学院计算技术研究所、中国科学院大学、蚂蚁集团
    核心价值问题：多智能体 LLM 系统里智能体之间的通信知识要么被忽略、要么被压成一个标量奖励，学不到“哪句话帮了忙”——怎么把通信变成细粒度的信用信号？
    方法：提出 OPSD4MAS，用在线策略自蒸馏把未来通信转为 token 级信用：外部模型抽事实、粗筛轨迹关系，再用留一法细筛目标 token 对智能体结果优势的影响，与 GRPO 线性退火联合优化。
    为什么值得看：数学任务 pass@4 相对 GRPO 最高提升 20 个百分点；多智能体协作里“谁的哪句话有用”这个信用分配问题，终于有了一个 token 级的解法。

    Turning Multi-Agent Communication into Token-Level Credit with On Policy Self Distillation

    关键词：多智能体系统（multi-agent systems）、强化学习（reinforcement learning）、通信信用（communication credit）、自蒸馏（self-distillation）

  8. 机构：蚂蚁集团、电子科技大学、浙江大学、东南大学
    核心价值问题：多智能体深度研究系统靠主智能体派活、子智能体回证据，但现有训练要么只训主智能体、要么给所有智能体发同样的团队优势——误导性报告可能被奖励、有用的报告可能被惩罚。
    方法：提出 LEAD-RL，主–子智能体联合 RL 训练 + 贡献感知信用分配：训练时用 rubric 评估每份子智能体报告的研究效用，据此门控它继承的团队优势，最终答案正确性是唯一的团队奖励。
    为什么值得看：BrowseComp 准确率提升 2.49 个百分点、关键路径成本下降 24.5%，五个基准、两个模型家族上均有提升；对做深度研究 agent 的团队，这是个可直接借鉴的训练框架。

    From Delegation to Coordination: Learning Efficient Multi-Agent Deep Research

    关键词：多智能体深度研究（multi-agent deep research）、强化学习（reinforcement learning）、信用分配（credit assignment）、Agent 训练（agent training）

  9. 机构：纽约大学、KAIST AI
    核心价值问题：agent 的 RL 只从标量奖励学习，试错中丰富的环境信息（如错误日志）被丢掉了；现有的反思/压缩 harness 能把经验传给下一轮，但“经验产物本身怎么写”却没人学。
    方法：提出 ACE-RL（Experience-Handoff RL），固定 ACE harness，用一个模型同时担任行动、反思、策展三个角色，按候选经验产物对未来 rollout 的下游效果评估，协同优化三者。
    为什么值得看：在多个 agentic 基准上 held-out 性能超过基线；它把“自改进”从调动作扩展到调“经验本身”，对递归自改进 agent 的设计是个新方向。

    Experience-Handoff Reinforcement Learning for Recursive Self-Improvement

    关键词：递归自改进（recursive self-improvement）、强化学习（reinforcement learning）、经验学习（experience learning）、Agent 优化（agent optimization）

  10. 机构：伦斯勒理工学院、IBM Research
    核心价值问题：工具 agent 任务分上去了、幻觉也上去了——模型明明推理出信息不够，却还是直接执行本该先问、先查或拒绝的调用，怎么让决策跟上当前任务状态？
    方法：提出 StateAlign：任务状态构建 + 状态对比 RL，覆盖五种任务条件，配对不同行动要求的状态；结果奖励管任务完成，token 级对比让同一推理在不同状态下产出适配的行动。
    为什么值得看：在 BFCL v4 多轮、ToolSandbox、When2Call 上，五个基座模型（三个家族）均有提升；Qwen3-8B 上多轮准确率最高、工具幻觉率最低；代码与模型已开源。

    StateAlign: Internalizing State-Aware Decision-Making for Reliable Multi-Turn Tool Agents via Reinforcement Learning

    关键词：工具 agent（tool agents）、强化学习（reinforcement learning）、状态感知（state awareness）、多轮对话（multi-turn dialogue）

  11. 机构：Brightendata
    核心价值问题：小开源模型适合私有化客服部署，但离前沿模型差得远；想从部署日志里自学，又不能把客户对话发给强 teacher 模型——没有 teacher 能不能自我进化？
    方法：无教师自进化：部署日志自我诊断、把规则写进 skill 库（代码检查、反例自审、配对重测、噪声校准验证门控），再用 GRPO 在完整多轮工具对话上训练 LoRA；harness 与权重两层一起进化。
    为什么值得看：Gemma 4 12B agent 两轮后 τ²-bench 零售/航空 pass¹ 分别提升 12.5/19.5 分，超过同模型全量策略提示的参考 agent，大幅缩小与前沿模型的差距；对私有化部署场景很实用。

    Knowledge in the Harness, Reliability in the Weights: Teacher-Free Co-Evolution of an LLM Agent

    关键词：Agent 自进化（agent self-evolution）、强化学习（reinforcement learning）、私有化部署（private deployment）、GRPO

  12. 机构：浙江大学、百度
    核心价值问题：决策模型当行动者常表现糟糕——但它能不能当个好老师？行动差的模型，评判与教学能力是否还值得用？
    方法：在 ALFWorld 上比较三类决策模型与三类通用 LLM 当行动者与评判者；再用 JEV 作教师，经 GRPO 训练策略：问“每一步是否有助于目标”而非“任务最终能否成功”。
    为什么值得看：JEV 自己行动在 ALFWorld 只有 42.9% 成功率，但作教师把 Qwen2.5-1.5B 从 72.8% 提到 82.9%（WebShop 56.8%→71.4%）；“行动差的模型仍可当好老师，但要问对问题”——对用小模型做 RL 奖励/评判的人有启发。

    Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents

    为什么值得看：结论分情况：用外部后训练教师时 OPD 通常输给 GRPO，还常让回答变长；但教师换成学生自己的 GRPO checkpoint 时，OPD 能以少 50 倍的蒸馏 FLOPs 恢复该 checkpoint 的数学准确率；多教师 OPD 把各领域 GRPO 专家合并成一个学生，蒸馏只占专家训练 FLOPs 的 5.2%–8.0%，两领域混合总 FLOPs 比联合 GRPO 少 42%。对"先 GRPO 再自蒸馏"的省算力路线是直接的实证依据。

    方法：刻画了约束漂移这一系统性失效模式：小更新下冲突对倾向于增加约束代价、一致对倾向于修复，净变化取决于两者平衡；由此给出可从数据集统计量直接算的预对齐诊断量 ρ*_eq（判断数据集是自纠正还是需要干预），并提出 Conflict-aware DPO（CoDPO），按 ρ*_eq 下调冲突对权重、再加自适应 margin 修正残余漂移。
    为什么值得看：偏好优化里一个真实存在但常被忽视的坑，给了先诊断、再修正的完整工具；四个领域上 CoDPO 在基本保留 DPO 偏好学习的同时降低了漂移，权衡优于硬过滤与约束/多目标基线。做 DPO 或偏好数据清洗的人可以直接用这个诊断量筛数据。
